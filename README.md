 NutriZen – AI Powered Food Health Analyzer

NutriZen is a MERN stack web application that helps users make healthier food choices by scanning product barcodes. It retrieves product information, analyzes ingredients and nutrition using Google's Gemini AI, assigns a health score, identifies harmful ingredients and preservatives, and recommends healthier alternatives from other brands.

Features

- 📷 Barcode Scanner
- 🤖 AI-powered Product Analysis (Google Gemini 2.5 Flash)
- 🥦 Health Score (0–10) with Color Indicators
- ⚠️ Preservative & Harmful Ingredient Detection
- 🛢️ Oil Type & Sugar Analysis
- 📊 Nutrition Breakdown Dashboard
- 💚 Healthy Alternative Recommendations
- 🔍 Product Search
- 🕒 Scan History
- ❤️ Favorites
- 📱 Responsive Modern UI

Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- Google Gemini API
- Open Food Facts API
- ZXing / HTML5 QR Code Scanner
- JWT Authentication

How It Works

1. Scan a product barcode.
2. Fetch product details from Open Food Facts.
3. Analyze ingredients and nutrition using Gemini AI.
4. Display a health score with detailed insights.
5. Recommend healthier alternatives if needed.
6. Cache products in MongoDB for faster future scans.
